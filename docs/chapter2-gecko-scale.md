# 第2章：ヤモリのサイズと脱皮場所の再調整（2026-09-12）

ガクチョの実プレイ指摘「ヤモリの部屋が簡単」「脱皮スポットが分かりづらい」を受けた追加調整。前回の受け入れ後に判明した課題として扱う。

## 大きさの根拠と判断

クロゴキブリの幼虫体長の目安は3齢約8 mm、4齢約11 mm。ただし腹部の伸縮で体長は変動する（[辻英明、2020、表1](https://www.jstage.jst.go.jp/article/pestology/35/1/35_pestology.35.1_15/_pdf)）。ニホンヤモリの形態研究では、頭胴長（尾を含めない）45 mm超の成体を調査対象としている（[Kim et al., 2019](https://link.springer.com/article/10.1186/s41610-019-0132-5)）。45 mmを全成体共通の最低値と断定するものではない。

ゲームのゴキブリは体長1.0を設計基準とするモデルに3齢1.02／4齢1.20を掛けている。ヤモリの原寸モデルは吻端X=3.12、尾の付け根X≈−1.65で、頭胴長の近似は4.77。吻端〜尾端のX方向外接寸法は約9.10（尾が曲がるため厳密な尾長ではない）。

| 設計寸法の近似 | 従来 scale .4 | 今回 scale 1.2 |
|---|---:|---:|
| ヤモリ頭胴長 | 1.91 | 5.72 |
| 3齢ゴキブリとの頭胴長比 | 1.87倍 | 5.61倍 |
| 4齢ゴキブリとの頭胴長比 | 1.59倍 | 4.77倍 |
| 尾込みX外接寸法 | 3.64 | 10.91 |

**2体のまま、ヤモリを従来の3倍へ拡大。** 成体と幼虫のサイズ差へ近づける方向であり、完全な実寸再現とはしない。ゴキブリの成長率はゲーム上約18%で、生物の体長目安8→11 mm（約38%）とは異なる。隙間の通行設計に関わるので今回ゴキブリの倍率は変更しない。倍率1.2、検知半径12、突進時間0.9秒はAI暫定値。

## 実装

- `createGecko(1.2)`を使用し、骨格・足運びも同じ倍率で生成。拡大時の旋回で到達不能な着地点になる問題を修正し、遊脚の着地点を現在の脚長で届く壁面上へ補正。尾が見える距離で模型全体が突然消えないよう描画範囲も拡張。2体の初期姿勢を縦向きにし、大部屋内へ体と尾を伸ばす。帰還は既存の後ずさりを使用。
- 検知半径9→12、狙い固定の突進0.65→0.9秒。観察1.1秒と予告0.9秒を経て攻撃。速度12は維持。
- 捕食は吻先から後方1.5までの頭部カプセル（半径.45＋プレイヤー半径）。尾や胴体に触れただけでは捕食しない。断熱材・壁が視線を遮れば接触判定も無効。頭部移動の障害物半径.45は維持。全身の壁・断熱材との衝突は従来からの残件。
- ガクチョ指定でMをB18へ移し、C18・D18も隙間へ。C18〜E18を幅1.4の連続した横隙間と解釈し、脱皮後も出入りできる。
- Mの床面を暗い退避穴と異なる淡いクリーム色・弱い発光に変更。局所光を置き、奥にある場所が入口から見えるようにする。追加の当たり判定のない装飾は置かない。プレイヤーの準備発光・Space長押し・成長後12%加速は維持。

## 検証

最終結果は `map.md` §6 の本調整ログと `artifacts/chapter2-gecko-verification.txt` に記録する。状態監査と通常キー入力での走破、拡大モデルの骨格監査、PNG目視を区別する。実機FPS・初見の怖さ・最終難易度・入口の気づきやすさはガクチョの実プレイ判断待ち。

- 状態監査：ムカデ3体の全巡回セル、全7敵の予告後接触、両ヤモリの遮蔽、B18での準備発光・長押し脱皮・再読込後の1.20/加速1.12を確認。
- ヤモリを個別に検証：もう1体の検知範囲外で距離10の獲物を置き、両個体とも2.74秒後に捕食。従来の半径9では検知されなかった位置。
- 通常キー入力のみの既知経路：脱皮なし5/8匹・104.2秒、脱皮あり7/8匹・148.8秒。座標・体力・敵の注入なし。実プレイの初見時間や難易度評価ではない。
- `GECKO_AUDIT_SCALE=1.2 node gecko-audit.mjs` と既定倍率.4の両方PASS。修正前に拡大個体の接地誤差最大.387を検出し、着地点補正後は約5e-16。骨格/材質の独立、停止、旋回、後ずさり、読み込み失敗からの再試行も確認。
- ゲームPNG（ヤモリ大部屋・脱皮入口・準備発光）と2D地図を目視。全身の地形衝突は未実装のままで、拡大個体の胴や脚が断熱材に重なる場合がある。
