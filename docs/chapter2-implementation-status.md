# 第2章「壁の中」実装現在地

記録日: 2026-09-09

## 現在プレイできる範囲

- `?chapter=2` で直接開始（8匹）。第1章からは実生存数を引き継ぐ。
- 壁内を下へ進む縦シャフト。断熱材、間柱、配線、配管、巾木、キッチン床下の順に構成する。
- 3齢の操作個体と、開始直後に別方向へ散る兄弟3体の演出。
- 3齢の身体幅で通れる／通れない横穴。通れる穴はムカデの追跡を解除する。
- ムカデは壁面前面に接するGLB 1体（黒緑の節板、黄褐色の15対の脚、赤褐色の頭部・尾脚）。0.6秒の粉塵予告後に頭部を向けて追跡し、頭部の接触だけで1匹を失う。巡回・警告・追跡・退避で、節の横うねり、左右交互の脚運び、触角・毒爪の動作量を変える（ゲーム側の手続きアニメーション）。
- 湿った配管分岐で、ゲジが10秒周期・0.65秒の脚音予告後に横断する視覚実装。

## ムカデ素材の再生成と組込み

- 再生成スクリプト: `assets/centipede-source/centipede_preview.py`。同スクリプトは確認用の真上／真横／斜俯瞰／正面寄りPNG、編集用 `.blend`、ゲーム用 `public/models/centipede.glb` を生成する。
- GLBはスタジオ床・照明・カメラを含まない。native glTFの -Z前方/+Y上を、第2章の壁面上で+X前方/+Z外向きに変換する。
- `src/centipede.ts` がGLTFLoader、影、節・脚・触角・毒爪の手続きアニメーションを担当する。リグやGLB内の歩行クリップは持たず、移動速度に応じてゲーム側で駆動する。
