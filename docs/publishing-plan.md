# G-survival 公開方針

決定日: 2026-09-08 / 決定者: ガクチョ

## 決定

本作は販売を目的とせず、できるだけ多くの人に遊んでもらうため全章を無料公開する。プレイヤーには一つの連続したWeb作品として届け、制作上は章ごとに独立したシーン・ルール・素材へ分離する。

- 一つのWebアプリ、一つの公開元、一つのセーブデータを基本とする。
- Vercel等の静的ホスティングでViteの `dist/` を配信し、ゲーム用バックエンドは当面持たない。
- `/chapter/1`、`/chapter/2` のような章別URLを用意する。通常プレイは状態を自動継承し、直接アクセス時は標準状態で開始する。
- 章ごとの別作品にはしない。兄弟の残数、身体状態、過去の場所の記憶を一続きに保つ。
- 開発中は章別プレビューURLを使い、章単位で実装・検証する。
- 初期セーブは同一オリジンのブラウザ保存を使う。章、解放章、生存数、齢期、身体サイズ、永続負傷をバージョン付きで保存する。
- 後からセーブコードまたはファイルの書き出しを追加できる形式にする。ログインやデータベースは当面導入しない。
- 3Dモデル、音声、イントロ素材は章ごとに遅延読み込みする。

## 章イントロ

各章冒頭に、季節、身体の変化、仲間との関係、生態を、短い文章と動く一枚絵または短い3D演出で詩的に伝える。攻略説明にはせず、初回自動再生、入力スキップ、後から再閲覧を可能にする。

第2章の核となる文は「大きくなるほど、通れなくなる」。白帯が消え、以前通れた隙間に胸部が引っかかり、兄弟が別々の暗がりへ消える変化を映像で示す。

## 制作順

1. 第1章を無料公開可能な品質まで整える。
2. 第2章で章遷移、セーブ、身体サイズ、章固有ルールの共通基盤を検証する。
3. 第3章で最大密度、終章で「逃げる」から「守る」への反転を検証する。
4. 残る章と演出を統合し、全章無料版として公開する。
