# 第2章 課題整理と調整順（2026-09-10）

ガクチョの実プレイ指摘を受け、原仕様 §9 と `docs/chapter2-spec.md` §4〜6・10を基準に再点検。従来の「実装完了」は到達性・体験の合格を意味しない。

| 優先順 | 確認した問題 | 調整と受け入れ条件 |
|---|---|---|
| 1 接触・退避 | ゲジはy=58〜64の帯全体、ヤモリはy=72〜84の帯全体を時間だけで捕食。隙間は左右非対称で、70地点の穴は脱皮後に入れない | 描画と同じ位置の身体接触に限定。各遭遇前後に成長後も使える穴。通常操作で退避でき、予告中は無害 |
| 2 空間・ゴール | 主通路はx=4〜10の幅6。横移動は袋小路のみ。y=88だけでクリア | 左右に広い壁に仕切り・迂回を配置。縦下降は維持し、右下のキッチン開口へ到達して終幕 |
| 3 地形 | 梁・配管は描画のみ。プレイヤーと敵は一定Zを直進 | 地形の高さ・遮蔽を移動と追跡に反映。登る／迂回する選択が安全につながる |
| 4 生物・カメラ | ムカデの非一様な潰しはないが、正面に近いカメラ。節だけが微小移動し、脚部品がそれぞれの中心で回転 | GLB形状を維持して斜めから描画。胴節と腹・脚を一緒に曲げ、脚の関節接続を保つ |
| 5 後半 | 自動監査は座標移動中心。ゲジを越えて到達できる根拠がない | 通常移動と時間進行で前半→ゲジ→ヤモリ→右下の出口。後半の画面も記録 |

未充足の元要件も分けて残す：触角による非言語の幅測定、面間の連続移動と滑落予告、資源のある横枝、兄弟の操作交代、イントロ再閲覧。これらを難易度数値の変更で代替しない。

横幅拡張・右下ゴール・立体化・歩行改善はガクチョ指定。具体的な寸法、敵の速度、退避口の間隔、カメラ角はAI暫定値。初見の発見性、恐怖感、FPS、8〜10分は実プレイ判定を要する。

## 今回の調整結果

- 通路幅6→24、左右の退避口10箇所＋狭い穴1箇所、高い仕切り4枚、登れる断熱材3箇所。縦下降を維持し、右下 x≥24/y≥89 で終幕。安全な横穴をチェックポイントとする。
- ゲジは身体付近のみ接触、ヤモリは0.9秒の予告で狙いを固定して突進。ムカデは地形の遮蔽で探知できず、高い仕切りと断熱材を頭部が貫通しない。
- 斜めからの追従カメラ、斜面高さと身体の傾斜、脚の股関節グループ化・胴節と腹部の連動を追加。GLB自体と形状比率は維持。
- `bash scripts/verify.sh` 全項目PASS（build、12群smoke、第1章260.7秒/13匹、browser、chapter2、nymph）。追加の `chapter2-route-audit.mjs` もPASSし、verifyへ組込み。開始からゴールまでは座標/敵の書き換えなし、キーイベントと通常の移動・敵更新を20msずつ進め、約54秒・8匹で終幕。続く局所回帰は位置を設定して、走って横穴へ逃げられること、仕切りを敵が貫通しないこと、斜面高さ、ゲジの旧死亡帯で無接触なら生存することを確認。
- 画面証跡: `artifacts/chapter2-route-70.png` / `chapter2-route-79.png` / `chapter2-route-ending.png`。静止画で仕切りの厚みと後半の描画を確認。実機の操作感・自然な歩行・FPSは未判定。

## 次の調整に残すこと

- 現状は広い空間と迂回・退避が成立する第一段階。短い既知経路を引き延ばす数値調整ではなく、資源や成長で選ぶ分岐を加える必要がある。8〜10分の体験は未達・未測定。
- 障害物対応は頭部の衝突と遮蔽。ムカデが全身の軌跡を保って角を回る経路追従、脚先の厳密な接地は未実装。
- 登れるのは今回追加した断熱材の斜面。配管・間柱の全接触面への連続移動、側面での貼り付きと落下予告は未実装。
- ヤモリ/ゲジの造形は簡易モデル。気流・粉塵・影による十分な非言語の予告、触角の幅測定は引き続き要改善。
