## 歩行

`src/geji.ts` の `loadGeji/createGeji/animateGeji/gejiDebug/disposeGeji` を使用。個体はSkeletonUtils.cloneで複製し、骨と材質を共有しない。

- 接地中は世界座標の足先を固定。身体が前進しても地面上の足先は滑らせない。
- 股関節〜膝〜足首の2節IKで、元の脚長を維持しながら膝を上方へ曲げる。足首以下は別骨で曲げ、遊脚は持ち上げて前へ送る。
- 移動距離で踏み替えを進める。前後の脚で位相をずらし、左右を半周期ずらす。歩幅1.25×縮尺、位相差.173、標準接地割合.64、持上げ.22×縮尺はAI暫定。
- 届かなくなる脚は早めに踏み替え、着地点も脚長内に制限する。狭い通路では`blockedAt`で材木への足先配置を避けて通路内へ寄せる。
- 停止時は進行中の遊脚を下ろして静止。触角のみ小さく探索する。再出現・瞬間移動・時計巻戻しは接地履歴を初期化。

`chapter2.ts` はロード・生成・描画呼び出しと開発用snapshotにのみ接続。横断周期、予告、捕食判定、地形、ヤモリ/ムカデは変更していない。
