# 第2章「壁の中」迷路化 実装メモ（2026-09-11、Claude/Opus 実装）

設計書は `docs/chapter2-maze-design.md`。ここは**実装した結果**の申し送り。

## 1. 実装した凡例（`src/chapter2-maze.ts` の `MAP`、46行×14文字、外周すべて `#`）

| 文字 | 意味 | 衝突 | 描画 |
|---|---|---|---|
| `#` | 間柱・木片 | プレイヤー・敵とも不可 | 材木ボックス（高さ `WALL_H=1.6`）。矩形へ貪欲マージして 1 メッシュ化 |
| `.` | 通路 | — | 描かない（壁板の表） |
| `~` | 断熱材の山 | 乗れる（`heightAt` 最大 1.2、すそ野 .6） | 台形メッシュ。高さ ≥.3 で地表の敵の接触を受けない |
| `1` | 細い隙間 1.10 | 3齢(1.02)は通り、4齢(1.20)は通らない。敵は不可 | 2本の柱（残り幅が実寸） |
| `2` | 広い隙間 1.40 | どちらの齢も通る。敵は不可 | 同上 |
| `o` `M` | 退避／脱皮ポケット | 敵は不可。中で `sheltered()` | 壁板を窪ませた袋（voidMat）。`M` は Space 3秒で脱皮 |
| `S` `G` | 開始／壁の穴 | 通路 | `G` は壁板を貫く穴（`ExtrudeGeometry` の hole）＋奥に台所の床と暖色ライト |
| `c` `g` `y` | ムカデ列／ゲジ行／ヤモリの巣 | 通路 | 敵の配置データ（下記） |

セル 2.0 ユニット。セル `(r,c)` → x∈[2+2c, 4+2c]、y∈[2r, 2r+2]。sim(x,y) → world(x,−y,z)。

**通行可否は幾何で決まる。** `blockedAt` は円（半径 = `bodySize/2`）と矩形の重なりだけで判定し、隙間セルは 2 本の柱の矩形として扱う。`reachable()` の BFS ルール（`1` は ≤1.10、`2` は ≤1.40）と一致する。

## 2. 敵の座標の取り方

`parseMaze()` が `MAP` から直接引く。`src/chapter2.ts` に定数は持たない。

- **ムカデ**: `centipede = {x, yTop, yBottom}`（`c` セルの列。現在 x=13 / y 19〜35 の 9 セル）。巡回は `yMid + sin(phase*.12)*yHalf` へ 2.2/s で寄る。視線が 1.0 秒以上切れると `recover`。
- **ゲジ**: `geji = {y, xLeft, xRight}`（`g` 行。現在 y=51 / x 9〜21 の 7 セル）。10秒周期、0.9秒予告のあと 3.9 秒で `xLeft-3` から横断。
- **ヤモリ**: `lair = {x,y}`（`y` セル。現在 13,71）。巣から半径 6 で検知、1.1 秒ためて 0.9 秒予告、0.65 秒突進。突進も `blockedAt(...,'enemy')` で壁に止まる。
- **脱皮 / ゴール**: `molt`（`M`）と `goal`（`G`）。プレイヤー中心が `G` セル内に入ると終幕。

`chapter2Test.maze` から同じデータを読めるので、監査スクリプトは座標をハードコードしない。`chapter2Test.route()` は現在の `bodySize` での BFS 経路をセル中心座標列で返す。

## 5. 設計書から変えた点

- **ムカデ列を主経路の縦断路にしなかった。** 設計書 §3 の文面（列＋両脇の退避）は満たしているが、BFS 最短経路が列を上から下へ縦断する配置では、降りてくるプレイヤーと登ってくるムカデが正面衝突し、退避を使わない限り回避できない（実測で 8→3 匹）。列は**主経路から分岐する袋小路のシャフト**（ムカデの巣）にし、主経路は行 9 でその口を通って右側を降りる。両脇の `2` 隙間＋`o` ポケット（行 11/13/15）は設計どおり残し、主経路から 5 セルで退避できる。
- シャフト区画の主経路上（行 12・col 11）に `2` 隙間を 1 つ足した。走って逃げ込める退避とチェックポイントを主経路に置くため。
- `blockedAt(x,y,r,who,bodySize)` の `bodySize` は未使用（通行可否は柱の実寸と半径 r で決まる）。設計書の署名に合わせて引数だけ残した。
- `renderAscii()` は `.` セルだけを `*` に置き換える（`c`/`g`/`~` などの凡例文字は残す）。
