# ムカデの動作調整（2026-09-11）

ガクチョ指定: 頭を中心に触角で進路を探る。脚が細かく動いてじわじわ進む。
参考: https://www.youtube.com/watch?v=6mzTmlibc_k （おーちゃんねる「生き物YouTuberの家に迷い込んだムカデの末路」）。ブラウザーで再生し10.2/10.4秒と10秒付近の連続画像を視覚確認。左右の触角の開閉差、頭側の曲がりと後方の緩い曲線、壁際の低い姿勢を参考にした。精密な歩容計測はしていない。

## 実装

- `src/centipede.ts`: 頭の移動履歴を距離でサンプリングし17節が追従。頭部と左右触角に個別の回転中心を設け、末端脚は尾節に追従。
- 歩行位相は実移動距離から計算。小振幅の接地送り72%と持ち上げ戻し28%を節ごとにずらす。停止中は脚の位相を保持し触角は探索を続ける。
- 背板と頭部の表示形状を丸め、背板の金属感と脚色を調整。GLBファイル自体は既存のまま、読み込み後のジオメトリを変更。
- `src/chapter2.ts`: 全身を常にプレイヤーへ回す処理を除去。壁からのモデル原点高さを0.72→0.02へ。巡回周期係数0.35→0.12（最大移動速度2.45→0.84）。追跡速度3.9と0.6秒予告・頭部接触判定は維持。
- 具体的な数値はすべてAI暫定値。ガクチョが指定したのは動作の方向性。

## 再現

WSL Node 23以降、開発サーバー起動後 `node centipede-motion-audit.mjs`。独立した描画ページで頭部のXY誤差、停止脚、動く触角、ページ例外を検証し `artifacts/centipede-motion-review.png` を生成。

実ゲームは `http://localhost:5173/?chapter=2`。実機の自然さ、FPS、恐怖感はガクチョ確認待ち。足先を世界座標へ固定するIKや触角による障害物検出は未実装。全身の障害物接触や配管面への追従も今回の視覚調整だけでは解決していない。
