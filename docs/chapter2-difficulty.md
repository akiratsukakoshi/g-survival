# 第2章 難易度・地形調整（2026-09-12）

ガクチョの課題は「簡単すぎる」「敵の特性を活かせていない」「脱皮の意味がない」。主経路に巡回する敵を置き、成長の移動速度向上と狭い経路の喪失を組み合わせる。旧設計の行き止まり8以上・最短110セル以上は今回の大部屋・近道指定で置き換える。難易度の合否は実プレイで判断する。

## 指定と実装範囲

- B07=1。ムカデは既存F10〜F18に加え、E08→L08→L06→I06とK18→J18→J16→L16→L14→J14→J12を往復する計3体。ルート上の地形は保持し、巡回線を別データで重ねる。
- MをB28からD18へ移動、E18=2、I18=断熱材。
- D22〜J22のゲジを追加（既存D26〜J26と合わせて2体）。
- ガクチョの追加回答によりD27/D28=1、J27/J28=2。
- 「29列〜40列」は図の29〜40行。B〜Mを一室にし、D31とK35にヤモリ各1体。断熱材を不規則に固定配置する（毎回の乱数は使わない）。
- Mに入ると第1章と同色・同周期の身体発光。Space 3秒長押しで脱皮し、脱皮中は移動停止。身体幅1.02→1.20と見た目を一致させ、脱皮後は歩行・ダッシュとも12%増（倍率はAI暫定値）。脱皮の強制クリア条件は追加しない。

## 段階と受け入れ条件

1. 地形：各指定セル、3齢/4齢の開始→ゴール・開始→M・M→ゴールを検証。巡回経路は隣接セルで連続し、敵不可セルを横切らない。
2. 敵：3体/2体/2体の独立状態、曲がる巡回と復帰、0.6秒ムカデ予告・0.9秒ゲジ/ヤモリ予告、接触による喪失、隙間への退避、断熱材によるヤモリ遮蔽を検証。ヤモリ検知半径9は大部屋向けAI暫定値。断熱材は敵が登らず、描画と同じ地形で視線を遮る。
3. 脱皮：M内の発光、退出で消灯、長押し完了、身体の成長、移動速度増、セーブ再読込、細い隙間拒否を検証。
4. `npm run build`・`scripts/verify.sh`・新規難易度監査・通常キー入力の走破・PNG目視確認。実機FPS・初見難易度・怖さはガクチョ確認待ち。

## 検証結果

- 配置監査：指定セル、外周、敵3/2/2、全巡回セルの連続性と身体半径での通行、成長前後の到達性を確認。最短経路は3齢104セル・4齢112セル、行き止まり5。旧「110セル/8行き止まり」は大部屋と近道の指定に合わせて廃止。
- 巡回監査：100秒の固定ステップでムカデの全9/13/12セルを訪問、頭の壁侵入なし。曲がり角を通る動作は頭部の判定と履歴追従を使用。全身の障害物接触判定は今回追加していない。
- 脱皮監査：M内発光、長押しを継続しても脱皮完了、幅・見た目1.20、通常歩行の0.5秒移動量1.30→1.456（1.12倍）、保存/再読込を確認。速度は歩行2.6→2.912、ダッシュ3.6→4.032。ムカデ追跡3.9は維持。
- ヤモリ遮蔽：両個体とも見通しありで予告し、断熱材の裏へ移ると予告・狙いが解除されることを確認。検知半径9、追加ゲジの周期位相差5秒、巡回0.84/復帰1.2はAI暫定値。
- 通常入力走破：状態を書き換えず、退避口/山でムカデを待ち、移動キーとSpaceのみ使用。脱皮なしは5/8匹・104.2シミュレーション秒、脱皮ありは5/8匹・162.5秒で終幕（経由セル数148、Mへの往復を含む）。難化指定により旧「7/8匹以上」を廃止し、両方の身体幅で生存して到達する条件へ変更。最短を無条件に走る操作では旧基準不合格・全滅も発生し、避難場所を使う入力に変更した。これは初見時間/体験の合格判定ではない。
- ゲーム画面：M発光、成長後、断熱材と2体のヤモリの画像を目視確認。最終2Dマップも確認。
- 全体verifyの結果はmap.mdの本セッションログへ記録。実機FPS・初見難易度・恐怖感はガクチョ待ち。

## APIと再検証

`parseMaze()` に `centipedes[{id,path}]` / `gejis[{y,xLeft,xRight}]` / `lairs[Ref]` を追加。旧 `centipede` / `geji` / `lair` は既存監査用に維持し、各先頭個体を指す。地形MAPと折れ線巡回の両方は `src/chapter2-maze.ts` が正本。`reachable(...,who='enemy')` は隙間・ポケット・断熱材を除外し、巡回復帰に使用する。

`chapter2Test.snapshot()` に `enemies` / `crossings` / `lizards` / `geckoVisuals` / `moltReady` / `glow` / `visualScale` / `speedMultiplier` を追加。`setEnemy`の末尾indexで個体指定可能、`route(to)`は目的セルを指定可能。モデルの+X前方/+Z背中、world(x,-simY,z)、既存のモデルAPIは保持。

`bash scripts/verify.sh`は`chapter2-difficulty-audit.mjs`も実行する。証跡は`artifacts/chapter2-difficulty-audit.json`とPNG。地図の再生成はNode v23以降をPATHに置いて`python3 scripts/export-chapter2-map.py`（Pillow/NotoSansJPが必要）。
