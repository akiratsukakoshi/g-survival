# G-survival -隙間の生-

クロゴキブリの幼虫として屋根裏を探索し、餌と水を確保して最初の脱皮を生き延びる、第1章のブラウザーゲームです。three.js + TypeScript / Vite を使用した横スクロール2.5Dで、壁面を8方向に這います。

## 起動と検証

WSL の `/home/tukapontas/g-survival` で実行します。

```bash
npm install
npm run dev
```

表示されたURLをPCブラウザーで開き、「卵から孵る」で開始します。音はこのクリック後に有効になります。音量スライダー、ミュート、確認音があります。

```bash
npm run build
node --experimental-strip-types smoke.mjs
node --experimental-strip-types playthrough.mjs --probe
# 開発サーバーを起動した状態で実行
node browser-audit.mjs
```

TypeScriptを直接読む検証には Node 23 以降を使います。ブラウザー検証には Playwright の Chromium が必要です。`npm run build` は配信用ファイルを `dist/` に出力します。

## 操作

| 入力 | 動作 |
|---|---|
| WASD / 矢印 | 壁面を8方向に移動 |
| マウス | 触角の向き |
| 左クリック長押し | 広く探る。移動速度は半分 |
| Shift | スタミナを使って走る。クモに振動を察知される |
| Space | 静止。餌と水が十分なら3秒長押しで脱皮開始 |

脱皮中の20秒間は移動できず、敵の攻撃も継続します。途中で捕食された場合は脱皮をやり直します。クモは音と気流で予告してから跳びかかります。予告された進路から離れると回避できます。アリの列に触れると群がられ、接触が続くと死亡します。障害物を迂回し、餌場と奥の隙間を探索してください。

個体が死ぬと、生きている仲間へランダムに操作が移ります。群れ表示は操作個体を含みます。糞の堆積は3箇所あり、近づくと仲間が集まり、休息で栄養と体力が回復します。水は水滴で補給します。
