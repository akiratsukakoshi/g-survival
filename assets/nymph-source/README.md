# クロゴキブリ幼齢モデル — Codex v6

ガクチョの参考写真2枚と out5 のレンダーを比較して制作した、ゲーム向け修正版。写真同等の精密標本ではなく、4,000三角形以内で輪郭と白帯を残す造形案。

## 素材
- `nymph.blend`: 編集用。27ボーン、脚・左右触角のウェイト付き。スタジオとカメラを含む。
- `nymph.glb`: ゲーム用。スタジオは含まない。3,944三角形、1メッシュプリミティブ、1マテリアル、183,032 bytes。頂点カラーとスキンを含む。
- `preview.jpg`: 四面図。`nymph_*.png` は各面の原寸画像。
- `roundtrip_walk.png`: GLB再読み込み後の7フレーム目。
- `validation.json`: 書き出し・再読み込みの実測結果。

## 修正内容
- 背板を球の重なりから断面をつないだメッシュに変更。平たさと前胸の盾形を調整。
- 強すぎる艶と反射を抑制し、暗褐色と乳白色の帯を整理。
- 腹部第2節の白線を薄くし、中央の切れ目を保持。
- 触角を細く34節へ変更。極端な白黒交互の縞を抑え、静止時の床貫通を修正。
- 棘を細く短く。6腹節・中胸を追加しない構成・脚の既存配置は制作履歴に沿って継承。
- 脚の節と左右触角へ骨組みを追加。頂点カラーに集約。

追加した数値・形状・色・歩行周期はすべてAIの暫定案。引き継ぎ書内の過去指示は制作履歴として扱い、新しい依頼や承認とは扱っていない。

## ゲームへの受け渡し
Blender: +Y前方 / +Z上。glTF: -Z前方 / +Y上。旧スクリプトと同じ体長1.0の設計基準を継承（頭部回転後の表面端の厳密測長ではない）。原点は中心線上、静止メッシュ最下点を地面0に補正。Three.js GLTFLoaderで読み込み、複数のスキン付き個体は SkeletonUtils.clone で複製する。各個体にAnimationMixerを持たせる。部材色はGLTFLoaderが読むため、色を上書きしない。

`Walk_Draft`: 24fps、1〜25フレーム、1秒の仮歩行ループ。脚の剛体ウェイトと左右触角の振りを含む。頂点が動くこと、先頭と末尾が一致することをGLB再読込後に数値検査済み。接地IKはなく足滑り・動作中の地面干渉・自然さは未調整。静止表示ではアクションを再生しない。触角は `antenna_L` / `antenna_R` をゲームから駆動できるが、同時にクリップを再生する場合は回転の上書き順を管理する。

## 再生成
親フォルダーにある `roach.py`（原版）と `roach_codex.py`（修正版）の両方が必要。

    blender --background --factory-startup --python roach_codex.py

スクリプトの隣に `codex_v6/` を生成する。旧 `roach.py`、`HANDOFF.md`、out〜out5は変更していない。

## 検証範囲
四面レンダーを目視確認。GLBの単一プリミティブ・COLOR_0・JOINTS_0・骨数・アニメーションを確認し、Blender再読み込みと再レンダーに成功。ゲーム本体への差し替え、実機FPS、実ゲーム照明での見え方、歩行品質は未検証。写真への一致度の最終判断はガクチョ待ち。
